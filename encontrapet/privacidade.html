Política de Privacidade - EncontraPet

Última atualização: 04 de agosto de 2026

1. Introdução

A presente Política de Privacidade descreve como o aplicativo EncontraPet ("aplicativo") coleta, usa e protege as informações dos seus usuários. Ao utilizar nosso aplicativo, você concorda com as práticas descritas nesta política.

2. Dados Coletados

O aplicativo EncontraPet coleta os seguintes dados:

Dado Finalidade Armazenamento
Nome do usuário Identificação e exibição no perfil Servidor em nuvem
E-mail Login e contato Servidor em nuvem
Telefone Contato entre usuários para devolução de pets Servidor em nuvem
Cidade Filtragem de posts por localização Servidor em nuvem
Foto do perfil Identificação visual do usuário Servidor em nuvem
Dados do pet (nome, espécie, raça, cor, tamanho, sexo, idade) Identificação do animal perdido/encontrado Servidor em nuvem
Localização (cidade, bairro, endereço, coordenadas) Busca e localização de pets Servidor em nuvem
Fotos do pet Identificação visual do animal Servidor em nuvem
Telefone de contato do post Contato entre usuários Servidor em nuvem

3. Dados que NÃO Coletamos

  • Dados de localização em tempo real (GPS)
  • Informações de pagamento
  • Dados de analytics ou rastreamento
  • Informações do dispositivo
  • Dados de navegação em outros sites

4. Permissões do Aplicativo

O aplicativo EncontraPet solicita apenas a seguinte permissão:

  • Acesso à internet: Necessário para enviar e receber dados dos servidores.

5. Compartilhamento de Dados

Os dados dos pets (descrição, fotos e localização) são compartilhados publicamente entre os usuários do aplicativo para facilitar a busca. Os dados pessoais do usuário (nome, e-mail, telefone) são compartilhados apenas quando um usuário entra em contato com outro sobre um pet.

Não vendemos seus dados pessoais para terceiros.

6. Segurança dos Dados

Utilizamos servidores seguros em nuvem para armazenar seus dados. As transmissões de dados são protegidas por criptografia HTTPS.

7. Retenção de Dados

Os dados são mantidos enquanto sua conta estiver ativa. Você pode solicitar a exclusão de seus dados a qualquer momento entrando em contato conosco.

8. Privacidade de Crianças

O aplicativo EncontraPet é adequado para todas as idades. Não coletamos dados pessoais de crianças de forma intencional.

9. Direitos do Usuário

De acordo com a Lei Geral de Proteção de Dados (LGPD), você tem o direito de:

  • Solicitar acesso aos seus dados pessoais
  • Solicitar correção de dados incompletos ou desatualizados
  • Solicitar a exclusão dos seus dados pessoais
  • Solicitar a portabilidade dos seus dados
  • Revogar o consentimento a qualquer momento

10. Alterações nesta Política

Podemos atualizar esta Política de Privacidade periodicamente. Quaisquer alterações serão refletidas na data de "Última atualização" acima.
